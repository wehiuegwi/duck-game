# Duck Rarity Roll

A tiny browser game where you roll a random duck, score it by rarity, and try to beat your best score.

## How to play

1. Open `index.html` in a browser.
2. Click `Roll a Duck` to generate a new duck.
3. Watch the rarity badge and score rise for lucky combinations.
4. Try to beat your personal best score stored in the browser.

## Files

- `index.html` — page structure
- `style.css` — game styling
- `script.js` — duck generation and scoring logic

## Optional GitHub Pages deployment

If you want to host it online:

1. Open your repository on GitHub.
2. Go to Settings → Pages.
3. Set the source to the `main` branch and root folder (`/`).
4. Save and wait for the site to publish.

The resulting URL will be something like:

`https://<your-username>.github.io/duck-game/`
